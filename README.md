# NEXORA

Демонстрационное веб-приложение об ИИ, технологиях и автоматизации.

## Запуск локально

Требуется Node.js актуальной LTS-версии.

```bash
npm install
npm run dev
```

Vite выведет локальный адрес, обычно `http://localhost:5173`.

## Production-сборка

```bash
npm run build
npm run preview
```

Готовая сборка появится в `dist/`.

## Возможности текущего MVP

- Адаптивная оболочка приложения и навигация по разделам.
- Dashboard с карточками и демонстрационной статистикой.
- Каталог ИИ-инструментов: поиск, фильтрация по категориям, карточки и избранное.
- Калькулятор потенциальной экономии времени с динамическим пересчётом и сохранением результатов.
- Конструктор демонстрационных workflow с добавлением/удалением блоков и сохранением сценариев.
- База знаний с поиском и модальными окнами статей.
- Переключение светлой/тёмной темы, настройки компактности и анимации.
- Локальное хранение данных в браузере.

## Ограничения

- Это клиентский MVP: серверной авторизации, синхронизации между устройствами и базы данных нет.
- Конструктор сохраняет визуальные сценарии, но не выполняет реальные интеграции.
- Статистика на главной — демонстрационная.
- Каталог содержит ссылки на сторонние сервисы; NEXORA не связана с ними.

## Структура

- `src/components/` — общие компоненты.
- `src/pages/` — разделы приложения.
- `src/data/` — демонстрационный контент.
- `src/services/` — локальное хранение.
- `src/styles/` — отдельные файлы стилей.
