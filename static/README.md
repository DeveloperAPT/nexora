# NEXORA — версия без Node.js

Это готовая статическая версия веб-приложения. Она запускается обычным открытием `index.html` в браузере. Не нужны Node.js, npm, Vite, сборка или локальный сервер.

## Запуск
1. Распакуй архив в любую папку.
2. Открой папку `static`.
3. Дважды нажми `index.html` — приложение откроется в браузере.

Для публикации на статическом хостинге загружай содержимое папки `static`. Все пути относительные. Google Fonts используется как необязательное улучшение; без интернета сайт использует системные шрифты.

## Что входит
- `index.html` — страница приложения.
- `styles.css` — все стили в одном файле.
- `app.js` — логика приложения и интерактивность в одном файле.
- `favicon.svg` — значок сайта.

## Возможности
- Обзорная панель и навигация между разделами.
- Каталог ИИ-инструментов: поиск, категории и избранное.
- Конструктор демонстрационных сценариев автоматизации с локальным сохранением.
- Калькулятор потенциальной экономии времени и история расчётов.
- База знаний с поиском и модальными окнами.
- Переключение темы, компактный режим и настройка анимаций.
- Адаптивная компоновка для узких экранов.

## Важно
Данные хранятся в локальном хранилище браузера и не синхронизируются между устройствами. Сценарии автоматизации — визуальная демонстрация, реальные действия во внешних сервисах не выполняются. Статистика на главной демонстрационная.

Исходные модульные файлы разработки находятся в `../src`, но для запуска они не нужны.
